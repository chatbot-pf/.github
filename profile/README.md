## 우리가 하는 일

AI 챗봇, 이미지 분석, 맞춤형 추천 시스템 등 검증된 AI 기술과 데이터 전문성으로
고객사의 비즈니스 디지털 전환을 지원합니다.

- **AI 챗봇 · 콜봇** — 멀티채널 문의 접수부터 상담원 라우팅까지 자동화
- **이미지 분석** — 도메인에 맞춘 비전 모델 설계와 운영
- **맞춤형 추천** — 데이터 기반 개인화 추천 시스템
- **웹 · 모바일 앱** — 기획부터 배포·운영까지
